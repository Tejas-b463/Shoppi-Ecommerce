🛍️ Shoppi Full Stack eCommerce Web App
Tech Stack:

Frontend: Next.js, Tailwind CSS, shadcn UI

Backend: Node.js, Express.js, MongoDB

Auth: Clerk

Payments: Stripe

Deployment: Vercel (Frontend), Railway (Backend)

🎯 Features Overview

👨‍💻 User Features:
Home page with featured products

Categories & Filters

Product listing & detail pages

Cart (Add/Remove/Update)

Wishlist (Add/Remove)

Signup/Login (Clerk)

Payment flow (Stripe)

Purchase history

🧑‍💼 Admin Dashboard:
Add/Edit/Delete products

View all users

View all purchases (who bought what)

Product inventory control

Sales analytics

Order status updates
